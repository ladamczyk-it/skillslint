# Skillslint

Skillslint lints [Agent Skills](https://github.com/anthropics/skills), the `SKILL.md` folders that agents such as Claude Code load as instructions. It runs two checks in one command: prose quality with [textlint](https://textlint.org/docs/getting-started), and a 0–100 quality score per skill from [agent-skills-cli](https://github.com/Karanjot786/agent-skills-cli). Any skill below the floors you set fails the run with exit code `1`.

> Content is verified against **`@ladamczyk/skillslint` v4.2.6**. See [`CHANGELOG.md`](https://github.com/ladamczyk-it/skillslint/blob/main/CHANGELOG.md) to verify accuracy.

## Why

Skills are prompts your agents run unattended, so a vague, misspelled or badly structured one fails silently: the agent just does worse. Skills made with Anthropic's [skill-creator](https://github.com/anthropics/skills/tree/main/skills/skill-creator) are generally good, but skills are also written and edited by hand, and more and more often by agents themselves. Skillslint catches the common mistakes in both cases, locally and in CI.

```bash
$ npx @ladamczyk/skillslint --path .claude/skills
```

For every skill it prints the textlint findings, then a score bar for overall, structure, clarity, specificity and advanced use, and finally whether every skill met its floor.

## Installation

Run directly without installing:

```bash
npx @ladamczyk/skillslint
```

Or add it as a dev dependency, for CI or a [qoq](./qoq.md) pipeline:

```bash
npm install --save-dev @ladamczyk/skillslint
```

It needs Node `^22.22.2`, `^24.15.0` or `>=26` and npm 10 or later. List all options with `npx @ladamczyk/skillslint -h`.
